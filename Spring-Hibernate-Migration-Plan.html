Spring Core + Hibernate Migration Plan

Jewelry Management System  |  Branch: feature/hibernate-migration  |  2026-02-27

Migrate from manual JDBC (HikariCP + hand-written SQL) to Spring IoC + Spring Data JPA + Hibernate, keeping the JavaFX UI layer completely untouched. No Spring Boot, no embedded web server.

// Before
public class ProductServiceImpl implements ProductService {
    private final ProductRepository repo;
    public ProductServiceImpl(ProductRepository repo) { this.repo = repo; }
}

// After
@Service
@Transactional
public class ProductServiceImpl implements ProductService {
    @Autowired private ProductRepository repo;

    @Override
    public List<ProductDTO> getAll() {
        return repo.findAll().stream().map(mapper::toDto).toList();
    }
}

Phase 6 — JavaFX Bridge (MainApp.java + Controllers)

MainApp.java

@Override
public void init() {
    SpringContext.init(); // Boot Spring once before any FXML loads
}

@Override
public void start(Stage stage) throws Exception {
    FXMLLoader loader = new FXMLLoader(getClass().getResource("/fxml/MainLayout.fxml"));
    // Tell JavaFX: get controllers FROM Spring (enables @Autowired in controllers)
    loader.setControllerFactory(SpringContext::getBean);
    Parent root = loader.load();
    // ... rest unchanged
}
